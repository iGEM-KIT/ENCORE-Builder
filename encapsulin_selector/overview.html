Help the Open NC Database grow

ENCORE is designed to be more than a collection of existing records. We want researchers to be able to propose new entries and updates as further nanocompartments are characterized.

New nanocompartment Additional assembly Engineered modification Pore or property data Corrections

To contribute, add a JSON file for the new entry (a template is in the data folder) and open a pull request on GitHub, or open an issue with the DOI or PDB entry, the sequence or identifier and the experimental conditions. Entries are reviewed scientifically before inclusion.

FROM GENETIC INFORMATION TO SHELL ARCHITECTURE

One protein sequence, different possible assemblies

A coding DNA sequence determines the amino-acid sequence of a shell protein through translation. But the protein sequence alone does not determine which shell architecture will be observed experimentally.

ONE PROTEIN → MULTIPLE ASSEMBLIES

Why is the architecture not unique?

EncA shell protein same WT amino-acid sequence→T=1 60 subunitsorT=3 180 subunits

For example, EncA has reported T=1 and T=3 assemblies. These are different arrangements of the same protein. The observed assembly depends on experimental context (such as expression, buffer, pH, ionic strength and cargo); selecting a CDS is not a guarantee of a specific T-number or diameter.

SCIENTIFIC & TECHNICAL GLOSSARY

The words behind the data

Use the definitions below whenever an abbreviation or a metric is unfamiliar. Expand a category or search by term.

Identities, sequences & variants 10 terms ⌄

Encapsulin

A protein nanocompartment: shell proteins self-assemble into a cage that can enclose cargo.

What is being studied

Candidate

A biological nanocompartment entry, usually organized under one UniProt accession. One candidate can have several assemblies.

Q1D6H4

UniProt ID

A stable identifier for a protein entry in the UniProt resource. It identifies a record; it is not an assembly name.

Q9WZP2

Assembly

A reported arrangement or structural state of a shell. One protein sequence can form different assemblies.

EncA T=1 and T=3

Wild Type (WT)

The natural reference protein sequence, without the engineered shell changes documented for a particular variant.

Shown in green

Engineered

A protein intentionally altered by substitutions, deletions, insertions or tags compared with a reference.

Shown in purple

Modified / Unmodified

Status of the shell protein relative to the curated WT sequence; a different cargo or T-number alone does not imply modification.

Original → new residues

Construct

The specific experimental or designed version used: it may include tags, linkers or an adapted DNA sequence.

3×His variant

Protein sequence

The ordered amino-acid chain that makes the shell protein. Its length is stated in amino acids (aa).

EncA: 287 aa

CDS

Coding DNA sequence translated into a protein. A Builder-approved CDS may differ in nucleotides from published experimental DNA.

5′→3′ DNA, nt
Structures, measurements & evidence 10 terms ⌄

T-number

Triangulation number used for icosahedral shell architecture; for conventional complete capsids, subunit count is 60 × T.

T=1 → 60 · T=3 → 180 · T=4 → 240

Symmetry

Overall structural organization, e.g. icosahedral or tetrahedral. A tetrahedral shell does not get a T-number by default.

Tetrahedral → T: N/A

Outer / inner diameter

Outer diameter measures the overall cage width; inner diameter approximates the available interior span.

Expressed in nm

Subunits

Number of shell protein copies in an assembly. Different architectures can use different counts.

EncA T=3: 180 subunits

Pore

Opening through the protein shell. Size, charge and conformation affect transport, but are condition-dependent.

Diameter in nm

Pore state / charge

An observed open/closed state and reported electrostatic environment; values may differ by pore and study.

Positive / negative / not reported

Empty / cargo-loaded

Whether the studied shell contains cargo protein. This state does not itself imply a mutated shell sequence.

Empty T=3 vs loaded T=3

PDB / structure ID

Identifier of a deposited structural model; it helps link properties to experimental evidence.

4PT2; 7S20

DOI / source

Publication identifier / scientific reference supporting a particular observation.

Paper linked to a measurement

Conditions / method

How evidence was generated: e.g. cryo-EM, buffer, temperature, pH. Values may not generalize.

Cryo-EM; pH where known
Units & missing information: nm = nanometres · aa = amino-acid residues · nt = nucleotides. Not reported does not mean zero; Not verified means insufficient confirmation; N/A means not applicable.
