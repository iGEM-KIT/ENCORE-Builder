 0. WAS IN DIESEM SCHRITT NEU DAZUKAM (zur Orientierung)
-------------------------------------------------------------------------------
Backend-Logik an einem Ort:  server/services/goldenGate/
  - data.js       Libraries + Golden-Gate-Konstanten (Single Source of Truth)
  - sequence.js   DNA-Helfer + Cargo-Validierung (Stopcodon-Erkennung)
  - design.js     Engine: Level 0 (mit Typ-Overhangs), Level 1/2, Primer,
                  Plate-Plan, Order-Liste, FASTA
  - index.js      Sammel-Export + getLibraries()

API-Endpunkte (Nuxt/Nitro):
  - GET  /api/libraries        -> Nanokompartments, Cargo-Presets, Linker, ...
  - POST /api/cargo/validate   -> Cargo-CDS prüfen (Stopcodons etc.)
  - POST /api/design           -> komplettes Golden-Gate-Design aus den
                                  3 Entscheidungen (NC, Cargo, C/N-Fusion)

Frontend-Anbindung (minimal, additiv, bricht nichts):
  - frontend/encore-builder.html: unten ein optionaler Block window.ENCORE_API
    (Health-Check + fetch-Helfer). Der Prototyp läuft weiter standalone.

WICHTIG: Konnte in dieser Umgebung NICHT ausgeführt werden, weil weder Node
noch pnpm installiert/auffindbar sind. Logik wurde per Code-Review gegen den
Prototyp verifiziert. Bitte lokal testen (siehe Abschnitt 8).
